PRIVACY — LAST UPDATED 2026-10-26

Nothing leaves the device

Orbit is a calculator. It does not need a server, an account, an advertising ID or a crash reporter, so it does not ask for them. The Android manifest contains no internet permission.

What Orbit stores

  • The last 100 calculations: the expression, its formatted result and the timestamp.
  • Memory register and settings: theme, accent palette, digit grouping, precision, haptics, DEG/RAD.
  • Nothing else. There is no profile, no identifier and no contact list access.

History and settings are stored as local JSON in the app's private storage. They are excluded from Android cloud backup and device-to-device transfer, so a reinstall starts clean.

What Orbit never does

  • It does not connect to the internet.
  • It does not include an analytics, crash-reporting or advertising SDK.
  • It does not read contacts, location, files, photos, microphone or camera.
  • It does not sell, share or transmit calculations, because it has no way to transmit them.

Clipboard

When you tap Copy, the formatted result is placed on the system clipboard. That action is initiated by you and handled by Android; Orbit does not read the clipboard in the background.

Sideloaded builds

The APK offered on this site is a debug-signed build for direct installation. It carries the same manifest and the same absence of network permission as the release build. Verify the hash printed in the build log if you want to confirm the file you installed.

Your control

Clear history at any time from the history sheet. Uninstalling Orbit removes its private storage. There is no remote copy to delete because no remote copy was ever made.

Contact

Questions about this policy can be sent to the address listed in the build's README. This is a single-developer project; replies are manual.
