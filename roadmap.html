ROADMAP

What comes next

Orbit 1.0 is shipped and stable. The list below is deliberately short: each item earns its place by making a daily calculation faster, not by adding a dashboard.

1.0

Shipped. Expression engine with live preview, scientific keypad with a 2nd bank, history and memory persistence, nine converters, exact bill splitter, four accent palettes, Material You, hardware keyboard support and 163 automated tests.

1.1

Next. A compact history panel that can be pinned beside the keypad in landscape, plus per-entry notes so a result can carry a label. Still offline, still one permission-free install.

1.2

Planned. Currency conversion with user-supplied rates (never fetched automatically), and a share-sheet action that sends a formatted calculation to another app.

Later

Exploring. Widgets for the home screen, a Wear OS companion, and expression variables such as tax = 0.11. All of these must pass the same privacy bar: no network, no account, no telemetry.

Dates are intentionally absent. This is a solo build; a version ships when the tests and the emulator pass, not when a calendar says so.
